# Next Experiment — Unlabeled Multi-Project Closure Challenge

The strongest next attack is to remove the favorable parts of this trial while retaining its evidence discipline.

## Goal

Freeze training on one or more deterministic project snapshots, then challenge learned closure on separate projects or versions whose held-out mutations do not carry declared risk tags. Include config generators, renames/deletes, opaque helper reads, longer derived-output chains, and checkpoint loss/corruption cases.

## Strongest gate

```text
silent stale outputs == 0
final oracle equality == true
every repair and quarantine retains provenance
total policy check work < full oracle check work
held-out inputs and oracle answers never enter training or routing
```

Unlike Experiment 05, count sparse executions in the primary work gate. Report scoring-oracle cost separately and attempt an independently checkable reduction without weakening miss detection.

## Failure rule

Freeze the challenge before its first scored run. Publish and minimize every miss. Do not relabel held-out changes, widen risk declarations, or modify a fixture merely to turn failure into a pass.
