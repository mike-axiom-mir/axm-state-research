AXM STATEBORN RPG LAB v0.6.0
================================

WHAT THIS IS
------------
A local bottom-up state research chain with six separately preserved steps.
The new State Language Microscope tests whether two bounded machines can
coordinate with typed state packets and no natural-language payload.

OPEN THE NEWEST TEST
--------------------
1. Open the "dist" folder.
2. Double-click "language.html".
3. Choose one of the five frozen held-out fixtures.
4. Step one packet at a time or run the selected protocol.
5. Compare the two machine views with the separate observer interpretation.
6. Inspect a solved, refused, ambiguous, and deadlocked route.
7. Run the refusal attacks and verify exact replay.
8. Run the complete held-out gate.

No account, internet, AI connection, installation, server, or real personal
data is required.

SIX KNOWLEDGE STEPS
--------------------
v0.1 canonical receipts: deterministic, but whole-world copy/hash scaled badly.
v0.2 sparse relations: sleeping logical cells plus causal autonomous reactions.
v0.3 curiosity boundary: novelty input separated from observer consequences.
v0.4 coexistence boundary: human/machine/AI-compatible proposals, one referee.
v0.5 ownership boundary: consented projections compose, return, and separate.
v0.6 protocol boundary: typed packets coordinate, refuse, or deadlock honestly.

All six named ZIP snapshots are retained. A later version does not rewrite an
earlier failure, fixture, limitation, or result.

WHAT TO WATCH
-------------
- Machine payloads contain typed state values, not prose.
- Fictional private values never appear in the channel.
- A commit binds two exact accept packet digests.
- Consent refusal and insufficient state remain visible failures.
- The ambiguous fixture reports unused valid alternatives.
- Text-bearing, tampered, and stale packets fail closed.
- Reverse offer order preserves the same normalized result.
